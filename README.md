## 🌿 Sobre el Proyecto

**PlanFlow ERP** es un sistema hecho a la medida diseñado para digitalizar, organizar y potenciar la producción de **REBEL Kombucha** y nuestras líneas de Yogurt. 

Dejamos atrás las complejas hojas de cálculo para dar paso a una plataforma centralizada que nos permite tener el control absoluto de nuestros procesos: desde la recepción de la materia prima, pasando por los tiempos exactos de fermentación, hasta el despacho de cada botella que llega a las manos de nuestros clientes.

## ✨ Lo que hacemos posible

- 📦 **Catálogo Maestro:** Gestión centralizada de nuestros productos, sabores y presentaciones.
- 🧪 **Fórmulas y Recetas:** Estandarización de nuestros ingredientes para garantizar que cada lote tenga el mismo sabor increíble de siempre.
- 🏭 **Control de Producción:** Trazabilidad total de cada lote. Registro en tiempo real de pH, temperaturas y tiempos para asegurar la máxima calidad.
- 📊 **Inventario Inteligente (Kardex):** Entradas y salidas automatizadas para saber exactamente qué tenemos en nuestro almacén en todo momento.
- 📈 **Centro de Control:** Paneles visuales para tomar decisiones rápidas y acertadas en el día a día.

## 🛠️ La base tecnológica

Este sistema está construido con mucho cuidado, utilizando herramientas modernas, ágiles y robustas para acompañar el crecimiento de la empresa en los próximos años:

- Desarrollado sobre **Laravel**.
- Interfaz gráfica limpia, rápida y adaptable.
- Base de datos segura para resguardar nuestra historia de producción.
